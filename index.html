Pagina informativa del programma automatico di lettura dati · Information page for the automated data reader

Che cos'è

AIBusinessOS-research-bot è un programma automatico che legge dati pubblici per ricerche di mercato su prodotti digitali per aziende. Usa soltanto interfacce (API) pubbliche e gratuite pensate per l'accesso automatico. Attualmente usa il servizio GDELT DOC 2.0 API.

Come si comporta

  • Si identifica sempre con lo User-Agent AIBusinessOS-research-bot/0.1 seguito dall'indirizzo di questa pagina.
  • Rispetta robots.txt: se il file non è raggiungibile per un errore del server, non accede.
  • Fa poche richieste, distanziate nel tempo, e rispetta il Crawl-delay. Si ferma alla prima risposta 429 o 403.
  • Non segue redirect, non usa proxy di terzi, non aggira CAPTCHA, blocchi o limiti di accesso.
  • Non effettua login, non compila moduli, non acquista nulla e non esegue pagamenti.
  • Non raccoglie dati personali. Conserva soltanto metadati e collegamenti, non copie dei contenuti.

Come bloccarlo

Aggiungete al vostro robots.txt:

User-agent: AIBusinessOS-research-bot
Disallow: /

Contatti

What it is

AIBusinessOS-research-bot is an automated program that reads public data for market research on digital B2B products. It only uses free public APIs intended for automated access. It currently uses the GDELT DOC 2.0 API.

How it behaves

  • It always identifies itself with the User-Agent AIBusinessOS-research-bot/0.1 followed by the address of this page.
  • It honours robots.txt. If the file cannot be fetched because of a server error, it does not access the site.
  • It sends few, spaced-out requests and honours Crawl-delay. It stops at the first 429 or 403 response.
  • It does not follow redirects, does not use third-party proxies, and never circumvents CAPTCHAs, blocks or access limits.
  • It does not log in, submit forms, buy anything or make payments.
  • It does not collect personal data. Only metadata and links are kept, not copies of the content.

How to block it

Add this to your robots.txt:

User-agent: AIBusinessOS-research-bot
Disallow: /
